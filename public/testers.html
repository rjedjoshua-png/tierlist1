# Quantum TierTagger

Quantum TierTagger is a client-side Fabric mod that displays PvP tier rankings from Quantum Tierlist directly on player nametags.

Features

  • 🏷️ Live tier tags — See every player's PvP tier in real time
  • 🎮 Multiple gamemodes — Sword, Axe, Crystal, Pot, SMP, UHC, NethPot, Mace, SpearMace, Cart
  • 🔍 In-game search — Look up any player's tier
  • ⌨️ Keybinds — Cycle gamemodes "G" or search "Y"

Requirements

  • Minecraft 1.21.1 – 1.21.11
  • Fabric Loader ≥ 0.16.0
  • Fabric API
  • ModMenu ≥ 11.0.3
  • Java 21+
